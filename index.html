Slack 채널 ID 확인 방법
Cardy는 채널 이름이 아니라 실제 Slack 채널 ID 또는 DM ID로 발행합니다. 아래 순서대로 확인한 뒤, 이름과 ID를 함께 저장해두면 이후에는 저장된 발행 대상에서 바로 선택할 수 있습니다.
1. Slack 데스크톱 또는 웹에서 대상 채널을 엽니다

발행하려는 공개 채널, 비공개 채널, 또는 DM 대화를 먼저 엽니다.

2. 채널 이름 클릭 후 정보 패널을 엽니다

상단 채널 이름을 누르면 우측 정보 패널이 열립니다. Slack 버전에 따라 ‘채널 세부정보’ 또는 ‘대화 정보’로 표시될 수 있습니다.

3. 하단의 채널 ID 또는 대화 ID를 복사합니다

보통 C..., G..., D... 형태입니다. 공개 채널은 C, 비공개 채널은 G, DM은 D로 시작하는 경우가 많습니다.

4. Cardy에서 이름과 ID를 함께 저장합니다

예: 이름은 개발공지, ID는 C0XXXXXXX. 저장 후에는 북마크처럼 재사용할 수 있습니다.

비공개 채널이나 DM으로 발행하려면 Slack 봇이 해당 대화에 접근 가능해야 합니다. 비공개 채널은 봇을 먼저 초대해야 하고, DM은 실제 DM 대화 ID를 사용해야 합니다.
