설치 안내

🍎 macOS
1

다운로드한 .dmg 파일을 열고, Cardy 아이콘을 Applications 폴더로 드래그합니다.

2

앱을 처음 실행하면 "손상되었거나 열 수 없습니다" 경고가 뜰 수 있습니다.
방법 A. 앱 아이콘 우클릭 → 열기 → 열기 클릭
방법 B. 터미널에서 아래 명령을 실행한 뒤 앱을 다시 열기:

xattr -cr /Applications/Cardy.app 클릭하면 복사됩니다
3

"확인 없이 열기" 방법: 시스템 설정 → 개인정보 보호 및 보안 → 하단 Cardy 항목 → 확인 없이 열기

ⓘ 이 경고는 Apple 인증서 없이 배포된 앱에서 표시됩니다. Cardy는 오픈소스이며 소스코드를 GitHub에서 확인할 수 있습니다.
🪟 Windows
1

다운로드한 _x64-setup.exe 파일을 실행합니다.

2

"Windows가 PC를 보호했습니다" SmartScreen 경고가 뜨면:

추가 정보 클릭 → 실행 클릭

3

설치가 완료되면 시작 메뉴 또는 바탕화면 바로가기에서 Cardy를 실행합니다.

4

Windows Defender가 차단할 경우: 알림에서 허용을 선택하거나,
Windows 보안 → 바이러스 및 위협 방지 → 허용에 추가합니다.

ⓘ SmartScreen은 서명되지 않은 소프트웨어를 경고합니다. Cardy는 오픈소스이며 소스코드를 GitHub에서 확인할 수 있습니다.
